# Triage (adapt: stub)

Use upstream's state machine: one **category** role (`bug`, `enhancement`) and one **state** role (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) per issue. Every comment triage posts starts with `> *This was generated by AI during triage.*`

hstack changes:

- **Labels are the project's.** Map each canonical role onto the project's existing GitHub labels (below) instead of creating new ones.
- **Verify the claim with the verification skill.** Reproduce a bug by driving the journey from the report, and attach the evidence directory. This matches the kit's "bugs: reproduce first" rule in `AGENTS.md`.
- **`ready-for-human` on a PR** means ready for human review and merge. Triage never merges.
